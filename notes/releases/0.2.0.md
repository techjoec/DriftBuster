# DriftBuster 0.2.0

## Core
- The detection engine, catalog, diff, hunt and secret scanning, multi-server orchestration, profiles, scheduling, registry scan, SQL export, reporting and capture run on .NET in `DriftBuster.Backend`; nothing else needs to be installed.
- Config identities stay distinct across applications that share a file name, and an unreadable file is skipped and reported instead of failing the host.
- XML canonicalisation keeps namespace prefixes, the diff planner detects content type for every file, and secret redaction always terminates.
- Slack, Teams and SMTP notification adapters are removed.

## Formats
- None

## GUI
- The multi-server tab scans in process through the backend.
- Release builds are self-contained publishes that carry the .NET runtime.

## Installer
- None

## Tooling
- New `driftbuster` console tool: `scan`, `diff`, `hunt`, `multi-server`, `profile`, `detection-profile`, `schedule`, `registry-scan`, `sql-export`, `report`, `capture`, `version`, `release` and `maint`.
- The PowerShell module requires PowerShell 7.6 and runs everything through the backend assembly.
- The offline runner runs on Windows PowerShell 5.1 with nothing to install.
- `driftbuster version` and `driftbuster release` handle version sync and release builds; `scripts/verify_coverage.sh` and `scripts/lint_all.sh` cover the .NET projects and PowerShell.
